# Anooshah — Birthday Gift Website 💖

A futuristic, cyber-romantic glassmorphism website designed as a birthday gift for **Anooshah**, matching the neon dark-mode UI aesthetic.

---

## 🌟 How to View the Website
You can simply **double-click** `index.html` to open it immediately in any web browser (Google Chrome, Microsoft Edge, Brave, Safari, etc.) — **no installations or servers required!**

---

## ✨ Features & Personalization Guide

### 1. Change Her Profile Picture 📸
- **Direct in browser:** Click on the avatar circle on the website. A file picker will appear allowing you to select her photo. It will automatically save in your browser.
- **Or via file:** Replace `assets/avatar.png` with her photo (keep the same name `avatar.png`).

### 2. The Interactive Floating Dock (Left Sidebar) 🛸
- **Home**: Focuses the main hero profile.
- **Journey / Memories / Gallery**: Opens the interactive Photo Vault modal (you can add your favorite pictures together!).
- **Love Letter**: Opens the heartfelt birthday letter modal.
- **Secret Vault**: An encrypted vault that unlocks with passcode `1234` or `anooshah` to reveal a private birthday note!
- **Music**: Toggles a soothing, dreamy cyber-romantic ambient chord progression made with the Web Audio API.

### 3. Hero Card (Anooshah) 👑
- Shows her name with futuristic glowing neon typography.
- Click the **"💖 2041 WISHES"** button to send wishes with bursting heart particles and chimes!

### 4. Interactive Bottom Cards 💌
- **Love Letters**: Click *"Open Love Letter →"* to read a full-screen birthday message. You can edit the text inside `index.html` (look for `<div class="modal-body letter-scroll">`).
- **Our Memories**: Opens the memory photo album.
- **Surprise Her**: Blasts a shower of floating glowing neon hearts and sparkles across the screen!
- **Play Vibe 🎵**: Plays sweet ambient melodic chimes in the background.

### 5. Right Side Interactive Column 🎁
- **Make a Birthday Wish**: Allows you or her to type a sweet nickname and a birthday wish, sending it with an animated toast confirmation.
- **Infinity & Beyond**: Romantic love counter.
- **Reasons Why You're Special (1, 2, 3)**: Click each card to reveal heartfelt romantic notes and celebration effects.

## 🚀 How to Share it with Anooshah

1. **Option A (Super Easy - Send as Zip):**
   - Right-click this folder (`anooshah`), click *Send to > Compressed (zipped) folder*.
   - Send the zip file to her. She just unzips and double-clicks `index.html`!

2. **Option B (Free Live Link via Netlify Drop or Vercel):**
   - Go to [Netlify Drop](https://app.netlify.com/drop).
   - Drag and drop this `anooshah` folder into the browser window.
   - You get a free, private live link in 10 seconds (e.g. `anooshah-bday.netlify.app`) to send to her phone or laptop!

3. **Option C (GitHub Pages):**
   - Push this folder to a GitHub repository and enable GitHub Pages in Repository Settings.
